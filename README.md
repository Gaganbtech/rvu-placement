# RVU Placement Portal 🎓🚀

A modern, comprehensive placement and career management portal designed for RV University. It connects students, recruiters, and placement coordinators with real-time analytics, opportunity tracking, AI-assisted career tools, and dedicated stakeholder portals.

---

## ✨ Features

- **🎯 Opportunity Explorer**: Browse internships, full-time roles, eligibility criteria, and job descriptions with intuitive filters.
- **📊 Placement Insights & Impact**: Interactive placement performance charts, school-wise distributions, top recruitment partners, and CTC trends.
- **🤖 AI Career Assistant**: Contextual career guidance, resume suggestions, and opportunity matching.
- **👨‍🎓 Student Portal**: Dedicated dashboard for tracking applications, interviews, test schedules, and profile building.
- **🏢 Recruiter Portal**: Talent search, candidate shortlisting, JD posting, and interview coordination.
- **🏛️ Management & Placement Cell**: Administrative oversight, aggregate metrics, and talent analytics across university schools.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + PostCSS
- **Icons**: Lucide React
- **Data Export**: XLSX (Excel handling)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Gaganbtech/rvu-placement.git
   cd rvu-placement
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
